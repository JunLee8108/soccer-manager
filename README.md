# 축구 매니저

가상의 리그 **슈퍼 디비전**에서 클럽 감독이 되어 선수단을 꾸리고, 전술을 짜고, 시즌을 치르는 모바일 웹 매니지먼트 게임입니다. 리그·클럽·선수는 모두 시드 기반으로 자동 생성되는 가상의 데이터입니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173 (같은 와이파이의 휴대폰에서도 접속 가능)
npm test           # 엔진 테스트 (경기 밸런스, 일정, 시즌 진행)
npm run build      # dist/ 에 정적 파일 생성
```

모바일 기준 해상도는 390×844이며, PC 브라우저에서는 가운데에 최대 430px 폭으로 표시됩니다.

## 현재 구현

### M1 — 한 시즌 플레이
- **새 게임**: 16개 클럽 중 선택, 저장 슬롯 3개, IndexedDB 자동 저장
- **홈**: 다음 경기, 순위·승점·팀 사기, 지난 경기 리포트, 받은 메시지
- **스쿼드 / 선수 상세**: 포지션 필터·정렬, 능력치 레이더, 1–20 세부 능력치, 시즌 기록
- **전술**: 포메이션 6종, 탭으로 선발·교체 명단 변경, 자동 선발, 팀 지시(스타일·압박·라인)
- **경기**: 분 단위 시뮬레이션과 문자 중계, 볼 위치·경기 흐름, 스탯·평점 탭, 하프타임, 경기 중 교체·전술 변경, 결과 바로 보기
- **리그**: 순위표, 라운드별 일정·결과, 득점·도움·평점 순위
- **시즌**: 30라운드 홈·원정 리그, 부상·경고 누적·퇴장 징계, 이사회 평가

### M2 — 육성
- **주간 성장**: 나이, 잠재력까지 남은 여유, 훈련 강도·집중, 훈련 시설, 출전 시간·평점, 성격(프로의식)에 따라 능력치가 오름
- **노화**: 30세부터 신체, 33세부터 기술 능력 하락 (골키퍼는 3년 늦게)
- **개인 훈련 프로그램**: 슈팅·패스·드리블·수비·피지컬·멘탈·골키핑 중 선택
- **성장 예측과 기록**: 훈련 화면의 이번 주 성장 예상, 선수별 성장 요인·능력 그래프·시즌 능력치 변화, 4라운드마다 코치 성장 보고서
- **유스 아카데미**: 시즌마다 유망주 입단(시설 수준에 따라 잠재력·인원 차등), 1군 승격·방출, 20세에 자동 정리
- **시즌 전환**: 프리시즌 성장, 은퇴, 계약 만료 선수 재계약·방출 결정, AI 구단 선수단 보충
- 이전 저장 데이터(v1)는 불러올 때 자동으로 변환됩니다

### M3 — 이적·재정
- **재정**: 라운드마다 관중 수입(홈)·스폰서·중계권 수입과 주급·시설 유지비 지출, 시즌 상금, 이사회가 정하는 이적 예산·주급 예산, 잔고 추이와 항목별 수입·지출
- **시설 투자**: 훈련·유스 시설 업그레이드 (비용·유지비 증가)
- **이적 시장**: 시즌 초(1–4라운드)와 중반(15–18라운드)에 개장, 포지션·가격·자유계약 필터로 선수 검색
- **스카우팅**: 스카우트 전에는 능력치가 범위로만 보이고 잠재력은 "?" — 1라운드 뒤 보고서로 정확히 파악
- **협상**: 구단과 이적료(수락/역제안/거절, 강팀 핵심 선수는 2배) → 선수와 주급·계약 기간
- **자유계약 선수**: 언제든 영입 가능, 방출·계약 만료 선수가 자유계약 시장으로
- **판매·방출·연장**: 판매 목록 등록 시 AI 구단이 제안, 위약금을 내고 계약 해지, 시즌 중 계약 연장
- **AI 이적**: AI 구단끼리 약한 포지션을 보강하고, 이적 소식으로 확인
- **이사회 신뢰도**: 결과·순위·재정에 따라 변동, 너무 낮으면 경질 → 다른 구단 제안 수락 또는 새 게임
- 이전 저장 데이터(v1·v2)는 불러올 때 자동으로 변환됩니다

### 경기 보드 (교체·전술)
- 교체·전술 버튼이나 하프타임·부상 시 경기가 멈추고 보드가 열림 (자동 열기는 끌 수 있음)
- 피치 위 선수마다 포지션 능력치(원 안), 체력(테두리), 오늘 평점(칩)
- 선수를 탭하면 슈팅·키패스·볼 탈취·패스 성공률과 경고 문구, 그 자리 기준으로 정렬된 교체 후보
- 교체 비교: 핵심 능력치 차이와 팀 전력·평균 체력 변화 확인 후 확정
- 코치 추천 교체(부상·체력·평점 추세·경고 위험·경기 상황 근거)
- 위치 바꾸기, 경기 중 포메이션 변경(최적 배치), 팀 지시
- 전술 화면의 원 안에도 그 자리 예상 능력치 표시

## 구조

```
src/
  engine/          게임 로직 (React와 분리된 순수 TypeScript, 시드 고정 난수)
    match/         분 단위 경기 엔진과 한국어 중계 문구
    generator.ts   리그·클럽·선수 생성
    season.ts      라운드 진행, 회복·부상, 시즌 전환
    development.ts 주간 성장·노화, 성장 예측
    offseason.ts   은퇴, 계약, 유스 입단, 선수단 보충
    finance.ts     수입·지출, 상금, 예산, 시설 투자
    transfers.ts   이적 시장, 스카우팅, 협상, AI 이적
    board.ts       이사회 신뢰도, 경질, 감독직 제안
    lineup.ts      자동 선발, 명단 보정
    ratings.ts     포지션별 능력치, 팀 전력
  store/           Zustand 상태 + 저장소(SaveRepository / IndexedDB)
  screens/         화면
  ui/              공용 컴포넌트, 아이콘, 차트
```

저장은 `SaveRepository` 인터페이스 뒤에 있어서, 이후 Supabase 클라우드 저장을 같은 인터페이스로 붙일 수 있습니다.
