# 축구 매니저

가상의 리그 **슈퍼 디비전**에서 클럽 감독이 되어 선수단을 꾸리고, 전술을 짜고, 시즌을 치르는 모바일 웹 매니지먼트 게임입니다. 리그·클럽·선수는 모두 시드 기반으로 자동 생성되는 가상의 데이터입니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173 (같은 와이파이의 휴대폰에서도 접속 가능)
npm test           # 엔진 테스트 (경기 밸런스, 일정, 시즌 진행)
npm run build      # dist/ 에 정적 파일 생성
```

모바일 기준 해상도는 390×844이며, PC 브라우저에서는 가운데에 최대 430px 폭으로 표시됩니다.

## 현재 구현 (M1)

- **새 게임**: 16개 클럽 중 선택, 저장 슬롯 3개, IndexedDB 자동 저장
- **홈**: 다음 경기, 순위·승점·팀 사기, 지난 경기 리포트, 받은 메시지
- **스쿼드 / 선수 상세**: 포지션 필터·정렬, 능력치 레이더, 1–20 세부 능력치, 시즌 기록
- **전술**: 포메이션 6종, 탭으로 선발·교체 명단 변경, 자동 선발, 팀 지시(스타일·압박·라인)
- **경기**: 분 단위 시뮬레이션과 문자 중계, 볼 위치·경기 흐름, 스탯·평점 탭, 하프타임, 경기 중 교체·전술 변경, 결과 바로 보기
- **리그**: 순위표, 라운드별 일정·결과, 득점·도움·평점 순위
- **클럽**: 훈련 집중·강도(컨디션 회복과 부상 위험에 반영), 재정 개요
- **시즌**: 30라운드 홈·원정 리그, 부상·경고 누적·퇴장 징계, 이사회 평가, 시즌 결산 후 다음 시즌

## 구조

```
src/
  engine/          게임 로직 (React와 분리된 순수 TypeScript, 시드 고정 난수)
    match/         분 단위 경기 엔진과 한국어 중계 문구
    generator.ts   리그·클럽·선수 생성
    season.ts      라운드 진행, 회복·부상, 시즌 전환
    lineup.ts      자동 선발, 명단 보정
    ratings.ts     포지션별 능력치, 팀 전력
  store/           Zustand 상태 + 저장소(SaveRepository / IndexedDB)
  screens/         화면
  ui/              공용 컴포넌트, 아이콘, 차트
```

저장은 `SaveRepository` 인터페이스 뒤에 있어서, 이후 Supabase 클라우드 저장을 같은 인터페이스로 붙일 수 있습니다.
